# numericalanalysis.gr

Landing page για το πανεπιστημιακό σύγγραμμα **«Εισαγωγή στην Αριθμητική
Ανάλυση»** — Β. Χ. Κοκκίνης, Ι. Θ. Κολέτσος (Εκδόσεις Τσότρας, 2023).

Κωδικός Ευδόξου `122075205` · ISBN `978-618-217-046-5`

## Τι είναι

Στατική σελίδα, ένα αρχείο, χωρίς build step και χωρίς εξαρτήσεις. Σκοπός:
ο διδάσκων που εξετάζει το σύγγραμμα για το μάθημά του να βρίσκει σε ένα
σημείο τον αναλυτικό πίνακα περιεχομένων, δείγμα κεφαλαίου και τα στοιχεία
δήλωσης στον Εύδοξο.

## Δομή

```
index.html                    η σελίδα
assets/cover.jpg              εξώφυλλο
pdf/periexomena.pdf           αναλυτικός πίνακας περιεχομένων
pdf/deigma-kefalaio-2.pdf     Κεφ. 2 — Επίλυση μη γραμμικών εξισώσεων (σελ. 27-104)
CNAME                         custom domain για GitHub Pages
```

Τα δύο PDF προέρχονται από την επίσημη καρτέλα του βιβλίου στον Εύδοξο
(`static.eudoxus.gr/books/05/`) και φιλοξενούνται εδώ ώστε να μην εξαρτάται
η σελίδα από τα paths τους.

## Deploy

GitHub Pages από το `main`, root. Το `CNAME` ορίζει το `numericalanalysis.gr`.

DNS στον registrar:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  <user>.github.io
```

## Συντήρηση

Η ενότητα «Πού διδάσκεται» παράγεται από τα δεδομένα του Ευδόξου και θέλει
ενημέρωση μία φορά τον χρόνο, όταν κλειδώσουν οι δηλώσεις (συνήθως Νοέμβριο).
